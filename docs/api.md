# API reference

Start the server (from the project root, after `python scripts/prepare_data.py` and
`python scripts/train_rule_baseline.py` at minimum -- a trained neural checkpoint is optional, the
API falls back to the rule baseline):
```bash
uvicorn api.main:app --reload --port 8000
```
Interactive docs: `http://127.0.0.1:8000/docs` (auto-generated by FastAPI from `api/schemas.py`).

## `GET /health`
```json
{"status": "ok", "default_model": "attn_bahdanau", "models_loaded": ["attn_bahdanau"],
 "rule_baseline_loaded": true, "device": "cpu"}
```

## `GET /models`
Lists every trained checkpoint found under `experiments/checkpoints/*/best.pt`, plus the rule
baseline if fitted, with `is_default` marking which one `/normalize` uses when `model` is omitted.

## `POST /normalize`
Request:
```json
{"text": "naku ivala college ki vellali", "n_best": 3, "beam_size": 4, "engine": "auto", "model": null}
```
* `engine`: `"auto"` (neural if any checkpoint exists, else rule) | `"neural"` | `"rule"`.
* `model`: run name from `/models` (e.g. `"attn_bahdanau"`); ignored when `engine: "rule"`.

Response:
```json
{"input": "naku ivala college ki vellali",
 "hypotheses": [{"text": "నాకు ఇవాళ college కి వెళ్ళాలి", "confidence": 0.94}],
 "engine_used": "neural", "model": "attn_bahdanau", "latency_ms": 12.3}
```

## `POST /normalize/batch`
Same fields, but `texts: [...]` (max `api.max_batch` in `config.yaml`, default 32) instead of
`text`; returns `{"results": [...one NormalizeResponse per input...], "total_latency_ms": ...}`.

## Errors
| Status | Meaning |
|---|---|
| 422 | Validation error (blank text, batch too large, text over `MAX_TEXT_CHARS`) |
| 404 | `model` name not found under `experiments/checkpoints/` |
| 429 | Rate limit exceeded (`api.rate_limit_per_min` in `config.yaml`, default 120/min per client IP) |
| 503 | No neural model trained yet AND no rule baseline fitted (run `scripts/train_rule_baseline.py`) |

## CORS
`api.cors_origins` in `config.yaml` defaults to `["*"]` for easy local development (the Chrome
extension's `chrome-extension://<id>` origin and the plain-HTML web demo both need this). Tighten
this before deploying anywhere public.
